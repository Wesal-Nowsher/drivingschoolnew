# DriveNew Driving School (Bahrain)

Static website: index.html (Home), lessons.html, pricing.html, about.html. Shared styles in assets/. Each page lives in its own folder (`/`, `/lessons/`, `/pricing/`, `/about/`) so URLs have no `.html`. Host on any static host (GitHub Pages, Netlify, Vercel) or preview locally with `python3 -m http.server`.
